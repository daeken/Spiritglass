# Spiritglass app icon

`AppIcon.png` is the transparent raster source. It was generated with the built-in
image generation tool using the imagegen skill, then copied into this repository.
The build script only resizes it to the standard macOS icon sizes and packages an
`.icns` file in `.build/Spiritglass.app/Contents/Resources/Spiritglass.icns`.

## Final generation prompt

Create a polished macOS application icon for "Spiritglass", a local monitoring app whose personality is an elegant paranormal spirit box. One square icon asset, 1024 by 1024 composition, transparent background outside the icon's silhouette. A substantial softly rounded-square vintage-futurist shortwave radio receiver, seen straight-on with a very slight dimensional perspective, fills about 85% of the canvas. Its housing is near-black charcoal enamel with restrained warm brushed-metal edges. The upper two thirds are a deep smoky glass window: inside it a single luminous mint/teal ectoplasmic waveform rises into the subtle silhouette of a friendly abstract ghost or veil, as though a spirit is speaking through radio static. This luminous shape should be beautifully simple and iconic, no cartoon eyes or mouth. Lower third: a finely restrained speaker grille and one large tactile analog tuning knob; two or three tiny amber indicator pips. Strong silhouette, excellent small-size legibility, exquisite dimensional lighting, smoked translucent glass, softly glowing cyan-green spectral signal, premium crafted macOS app icon quality. Mysterious and inviting, understated occult instrumentation. Preserve ample transparent padding and a delicate natural contact shadow. No text, no letters, no wordmark, no watermark, no extra objects, no scene background. Render the final icon itself, not a mockup or a sheet of variants.
